# Swiggy Landing Page Clone

A responsive clone of the Swiggy homepage built with **HTML5 and CSS3 only** (no JavaScript, no frameworks). I made it as a frontend assignment to practice layout, responsiveness and matching a real design.

> This project is for learning only. It is not affiliated with Swiggy. All logos, brand names and food images belong to their respective owners.

## Sections Included

- Navigation bar with logo, Swiggy Corporate, Partner with us, Get the App and Sign in
- Orange hero banner with heading, delivery location input and search bar
- Three service cards: Food Delivery, Instamart and Dineout
- "Order our best food options" category section
- "Shop groceries on Instamart" category section
- "Discover best restaurants on Dineout" cards
- Get the Swiggy App banner
- Cities with food delivery
- Footer with company links, contact, legal, cities, social icons and app store buttons

## Built With

- HTML5
- CSS3 (Flexbox, CSS Grid, media queries)

## Responsive Design

The layout adjusts to desktop, tablet and mobile screens with media queries at `900px`, `620px` and `360px`. There is no horizontal scrolling on any screen size.
